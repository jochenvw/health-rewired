# SYNTHETIC cross-border referral package template

> Fictional template written for the Oncology Hackathon 2026 Munich. Every referral drafted from
> this template is a draft for human review – nothing is ever sent automatically.

## Sections every package must contain

1. Cover letter to the receiving trial team (in the site language)
2. Patient summary: age, diagnosis, stage, prior lines and response, current performance status
3. Molecular result: alteration, method, copy number / VAF, evidence tier
4. Eligibility evidence: each trial criterion with met / not met / unknown and its source
5. Attachments list: WGS report, recent imaging, recent labs, cardiac assessment
6. Administrative: EU S2 / prior authorisation status, interpreter need, travel and accommodation
7. Consent status and contact details of the referring oncologist
