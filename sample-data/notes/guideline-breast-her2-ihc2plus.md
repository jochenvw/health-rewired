# HER2 IHC 2+ (equivocal) – reflex ISH pathway, luminal B breast cancer

- IHC 2+ is equivocal by definition: reflex in-situ hybridisation (ISH/FISH) is required before
  HER2 status can be reported as positive or negative.
- If ISH shows amplification: treat as HER2-positive. Add anti-HER2 therapy
  (trastuzumab ± pertuzumab) to the neoadjuvant chemotherapy backbone.
- If ISH is not amplified: treat as HER2-negative, luminal disease. Chemotherapy choice follows
  ER/PR/Ki-67 risk; anti-HER2 therapy is not indicated.
- Do not start anti-HER2 therapy, and do not rule it out, before the ISH result is available. If
  chemotherapy must start before ISH resolves, flag the open question explicitly for the tumour
  board and re-discuss as soon as the result is in.
- Taxane-based regimens warrant closer neuropathy monitoring in patients with pre-existing
  diabetic peripheral neuropathy; consider dose modification thresholds agreed at MDT.
