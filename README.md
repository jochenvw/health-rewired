# Health Rewired

Health Rewired is a hackathon collaboration space for turning oncology ideas into working
prototypes. Participants contribute use cases as GitHub issues and assign suitable issues to the
GitHub Copilot coding agent for implementation.

## How it works

1. Create an issue describing an oncology-related problem and the expected outcome.
2. Assign the issue to GitHub Copilot.
3. Review, test, and improve the resulting pull request together.

Only oncology-related use cases are accepted.
